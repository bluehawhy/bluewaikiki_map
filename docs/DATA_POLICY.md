# 데이터 출처 · 접근 정책 · 장애 복구

## 출처 및 권리

- 각 버전의 출처, 출처 URL, 출처표시, 이용 조건, SHA-256, 수집 날짜를 함께 기록한다.
- 국토지리정보원 자료라 하더라도 파일 유형, 범위, 배포 경로에 따라 이용/재제공 조건이 다를 수 있다. 다운로드 동의 및 최종 이용조건 확인 전 공용 API로 공개하지 않는다.
- 일반 공개 지도 이미지·타일을 만들어 배포하는 서비스가 아니라, 허가된 도로/차선 공간정보를 내부 프로젝트용 API로 제공하는 것이 초기 목적이다.

## 서비스 분리

- 지도 DB는 독립 Docker 볼륨만 사용한다. 지도 API는 다른 BlueWaikiki DB를 조회·수정하지 않는다. 향후 일반 기능은 별도 DB 연결 모듈로 공용 PostgreSQL 프로젝트 DB만 사용한다.
- 기본 API 바인딩 `127.0.0.1:18083`, `/v1/*`에는 Bearer 인증을 요구한다.
- 원본 ZIP, 비밀번호, 토큰, 인증정보를 GitHub에 올리지 않는다. 최초 `.env`는 설치 스크립트가 로컬에서 생성한다.

## 갱신/장애 대책

- 작업 시간: KST 01~05시. 매 주기 1분 평균 load를 확인하고 임계치 초과 시 작업을 시작하지 않는다. 단일 worker 및 DB advisory lock을 사용한다.
- ZIP SHA-256, 필수 sidecar, .prj, 지오메트리 유효성, 최소 피처 수를 검사한다.
- 새 데이터를 전량 적재한 후 활성 포인터 교체. 어느 단계에서 실패해도 이전 활성 dataset은 유지된다.
- 이전 버전과 원본 ZIP은 자동으로 삭제하지 않는다. 저장공간이 부족하면 신규 갱신만 실패할 수 있으며, 기존 API는 유지된다.
- 실패한 동일 파일은 자동 무한 재시도하지 않고 작업자 확인 후 명시적 재시도한다.
- 운영 백업에는 PostgreSQL dump와 /data/raw, .env를 포함한다. 비밀정보는 암호화·권한 제한 하에 별도 보관한다.

## 미구현/후속

- 공식 인증 다운로드 어댑터 및 데이터 제공기관별 라이선스 검증
- 특정 레이어를 차로중심선/정지선/신호기로 분류하는 명세 기반 카탈로그
- 데이터셋별 partition/증분 동기화 및 보관 만료 정책
- 외부 공개/대량 호출을 위한 rate limiting, 비용·쿼터 관리
