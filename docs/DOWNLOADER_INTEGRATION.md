# 정밀도로지도 다운로드 어댑터: 추후 구현

**현재 상태: 미구현. 자동 로그인/웹 스크래핑/원격 다운로드는 동작하지 않음.**

1. 국토정보플랫폼과 데이터 제공기관의 공식 파일/API/대량배포 방법 및 자동화 허용 범위를 확인한다.
2. 자동 로그인이 허용된다면 비밀정보는 서버 Secret/보호된 환경변수로만 입력하고, 브라우저 세션·인증정보를 로그에 남기지 않는다. 보안문자·접근 제한을 우회하지 않는다.
3. 데이터 제공 방식이 전용 Windows 전송 프로그램이면 Ubuntu 호환성/라이선스를 확인하고, 지원이 없으면 공식 배치 파일 수동 확보를 우선한다.
4. 다운로드 어댑터는 `.partial` 임시 파일에 다운로드하고 SHA-256 검증 후 `.zip`으로 원자적 이동한다.
5. 자료 묶음별 `dataset_key`, `version`, `source_name`, `source_url`, `attribution`, `usage_rights`, 실제 SHA-256을 기록한 JSON manifest를 **ZIP 완성 후 마지막에** 원자적으로 저장한다.
6. 작업자는 신규 manifest를 발견하면 야간/저부하 조건에서 순차 적재한다. 실패한 업로드는 활성 자료를 건드리지 않는다.
7. 자동 다운로드 빈도와 변경분 감지 전략은 공식 데이터 갱신 주기/쿼터가 확인된 후 결정한다. 매일 전체 파일을 다시 받는 것은 기본 설정하지 않는다.

## 코드 접점

- `app/downloader.py`: `download_if_enabled()` 확장
- `app/scheduler.py`: 허용 시간대/부하 검사 후 다운로드 호출, inbox 적재
- `app/importer.py`: 공급 수단과 관계없는 파일 검증·GIS 정규화·스냅샷 공개

공식적인 다운로드 경로가 확인되지 않으면 데이터 파일을 직접 확보하여 `/data/inbox`에 놓는 반자동 모드를 유지한다.
